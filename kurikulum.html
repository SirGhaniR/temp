Kurikulum Unggulan Program Keahlian PPLG Berbasis AI

SMK Prakarya Internasional

Dokumen ini memuat rancangan kurikulum komprehensif untuk Program Keahlian Pengembangan Perangkat Lunak dan Gim (PPLG) di SMK Prakarya Internasional dari Kelas X, XI, hingga XII. Kurikulum ini dirancang dengan pendekatan "Beyond Curriculum" yang mengintegrasikan kecerdasan buatan (AI), standardisasi industri modern, serta pengembangan portofolio nyata untuk memastikan daya saing lulusan di tingkat global.

1. Struktur Kurikulum Kelas X: Dasar-Dasar PPLG & Logika Pemrograman

Fokus utama kelas X adalah membangun fondasi logika pemrograman yang kuat, pemahaman UI/UX menggunakan Figma, serta implementasi dasar aplikasi desktop dan gim sederhana dengan C#.

Semester 1: UI/UX Design & Dasar Pemrograman C#

Modul / Materi Deskripsi Pembelajaran Target Kompetensi (Goals)
UI/UX Prototyping with Figma Siswa mempelajari prinsip dasar desain antarmuka pengguna, pembuatan wireframe, komponen, varian, dan pembuatan prototipe interaktif aplikasi di Figma. Mampu merancang cetak biru aplikasi desktop dan gim sebelum masuk ke tahap pengodean.
Dasar Algoritma & Logika Pemrograman Pengenalan konsep berpikir komputasional, flowchart, tipe data, variabel, operator, dan struktur kontrol keputusan (if-else, switch-case). Memiliki kemampuan dasar memecahkan masalah komputasi secara terstruktur.
Sintaksis & Struktur C# Pengenalan lingkungan kerja (.NET/Visual Studio), sintaksis dasar C#, struktur perulangan (for, while, do-while), dan penggunaan array. Mampu menulis kode program berbasis teks (Console Application) dengan C#.

Semester 2: Pemrograman Berorientasi Objek (OOP) & Fundamental Gim

Modul / Materi Deskripsi Pembelajaran Target Kompetensi (Goals)
Object-Oriented Programming (OOP) Konsep Class, Object, Encapsulation, Inheritance, dan Polymorphism dalam bahasa pemrograman C#. Mampu mengorganisasi kode program secara modular dan profesional sesuai standar industri.
Aplikasi Desktop Sederhana (Windows Forms / WPF) Pengembangan aplikasi GUI desktop menggunakan C#, menangani event handling, dan integrasi komponen UI berdasarkan desain Figma. Mampu membangun aplikasi kasir, manajemen perpustakaan, atau utilitas desktop mandiri.
Fundamental Game Development Pengenalan game engine (Unity), logika pergerakan objek, sistem koordinat, dan manipulasi aset 2D sederhana menggunakan skrip C#. Mampu membuat gim berbasis 2D sederhana seperti Flappy Bird clone atau Pong.

2. Struktur Kurikulum Kelas XI: Full-Stack Web Development & Mobile App

Fokus utama kelas XI adalah membangun pemahaman arsitektur client-server, pengembangan web berskala penuh terintegrasi API AI, serta transisi ke pemrograman aplikasi mobile.

Semester 1: Full-Stack Web Development & Integrasi AI

Modul / Materi Deskripsi Pembelajaran Target Kompetensi (Goals)
Modern Frontend (HTML, CSS, Tailwind) Penyusunan struktur halaman web, styling modern dengan utility-first framework Tailwind CSS, dan penerapan JavaScript modern (ES6+). Mampu mengonversi desain Figma secara presisi menjadi tampilan web responsif.
Backend Framework & Database (Laravel / Express) Pengembangan logika server, routing, arsitektur MVC, manajemen basis data relasional (MySQL) menggunakan Eloquent ORM atau Query Builder. Mampu membangun sistem autentikasi, operasi CRUD, dan sistem manajemen data yang aman.
AI API Integration Mempelajari cara mengonsumsi RESTful API dari penyedia kecerdasan buatan (OpenAI / Gemini API) untuk membuat fitur cerdas di dalam website. Mampu menciptakan produk web inovatif seperti Generator Konten Otomatis atau Chatbot Rekomendasi Pintar.

Semester 2: Cross-Platform Mobile App Development

Modul / Materi Deskripsi Pembelajaran Target Kompetensi (Goals)
Hybrid Mobile Framework (React Native / Flutter) Arsitektur aplikasi mobile lintas platform, manajemen state, penanganan navigasi, dan integrasi komponen UI native. Mampu membangun aplikasi Android dan iOS dari satu basis kode tunggal menggunakan JavaScript/TypeScript/Dart[cite: 1].
Mobile API Consumption Menghubungkan aplikasi mobile dengan API backend yang telah dibangun pada Semester 1, manajemen penyimpanan lokal (Local Storage/AsyncStorage). Mampu membuat aplikasi mobile dinamis yang terhubung langsung dengan server internet global.

3. Struktur Kurikulum Kelas XII: Advanced Engineering, DevOps & Portofolio

Fokus utama kelas XII adalah standardisasi industri, kesiapan karir global, pengelolaan infrastruktur cloud, serta penyelesaian proyek akhir berskala besar.

Semester 1: DevOps, Cloud Administration & Efisiensi AI

Modul / Materi Deskripsi Pembelajaran Target Kompetensi (Goals)
Docker & Containerization Konsep kontainerisasi aplikasi, pembuatan Dockerfile, isolasi environment pengembangan agar konsisten dari lokal hingga server produksi. Mampu membungkus microservices atau aplikasi web ke dalam kontainer mandiri yang siap distribusi.
Cloud Server Administration (Ubuntu) Manajemen Virtual Private Server (VPS) berbasis Linux Ubuntu Server, pengamanan akses SSH Key, dan konfigurasi reverse proxy menggunakan Nginx. Mampu melakukan deployment aplikasi secara mandiri ke infrastruktur cloud publik (DigitalOcean, AWS, dll)[cite: 1].
AI Tools for Advanced Coding Pemanfaatan alat bantu kecerdasan buatan (GitHub Copilot/Cursor) untuk optimasi performa query database, refactoring kode, dan penulisan otomatis unit testing. Mampu meningkatkan efisiensi dan produktivitas pemrograman harian setara standar developer berpengalaman.

Semester 2: Capstone Project & Kesiapan Karir Industri

Modul / Materi Deskripsi Pembelajaran Target Kompetensi (Goals)
Capstone Project (AI-Based Software Solution) Kerja tim kolaboratif untuk memecahkan studi kasus nyata menggunakan arsitektur perangkat lunak yang telah dipelajari, dilengkapi dengan modul kecerdasan buatan. Menghasilkan produk perangkat lunak atau gim utuh berskala industri yang siap dipresentasikan.
Professional Portfolio Development Standardisasi repositori GitHub secara profesional, pembuatan dokumentasi proyek (README.md), kurasi resume (CV), serta optimalisasi profil LinkedIn. Siswa memiliki portofolio digital yang solid dan kredibel untuk memikat recruiter perusahaan teknologi nasional maupun global.
Uji Kompetensi Keahlian (Ujikom) Mandiri Simulasi live coding, uji ketahanan aplikasi, pengujian fitur keamanan, serta presentasi teknis di hadapan penguji eksternal dari praktisi industri tech terkemuka. Kelulusan bersertifikasi industri yang membuktikan kesiapan kerja penuh (Full-Stack / AI-Junior Dev).
